#### 2-2) codebook 컬럼 매핑
검증에 사용할 codebook의 컬럼을 지정합니다.
데모 데이터에서는 다음과 같이 매핑합니다.

|변수명 컬럼|변수명이 기재된 컬럼을 선택합니다.|변수명|
|eCRF명/시트명 컬럼|해당 변수가 속한 시트명(eCRF명)이 기재된 컬럼을 선택합니다.|eCRF명_1|
|코드리스트 컬럼|허용값 또는 범위가 기재된 컬럼을 선택합니다.|코드리스트|
|항목명/설명 컬럼|변수의 한글 설명(라벨)이 기재된 컬럼을 선택합니다.|항목명|
|데이터 유형 컬럼 (선택)|date, integer 등 데이터 유형이 기재된 컬럼을 선택합니다. 없으면 '(없음)'을 선택합니다.|데이터유형|

#### 2-3) 검증 옵션 (선택)
필요한 경우에만 설정합니다.

|코드북 대조 및 값 검증 제외 변수|Subject ID처럼 코드리스트가 없지만 문제없는 변수를 선택합니다. 여기 포함한 변수는 3.코드리스트 분류 확인에서 반드시 free_text로 지정해야 합니다.|SUBJNO, VISITNM|
|공통값 비교 제외 변수|동일 변수명을 쓰지만 시트마다 값이 달라도 되는 변수를 선택합니다.|LASTDT (연구자 마지막 확인일)|
|같은 날 방문 허용|방문명은 다르지만 방문일이 같을 수 있는 방문을 선택합니다.|해당 시 방문명 선택 (예: Screening)|
|집계 임계값|같은 오류가 이 값보다 많으면 한 행으로 축약해서 보여줍니다.|10|
|패턴 임계값|한 변수의 unique 값 개수가 이 값보다 많으면 'O'로 표시합니다.|10|

설정을 마치면 화면 하단의 **[현재 설정을 settings.xlsx로 저장]** 버튼으로 다운로드할 수 있습니다. 다음에 같은 연구 데이터를 검증할 때 이 파일을 업로드하면 위 설정이 자동으로 채워집니다.

### 4) 코드리스트 분류 확인
codebook의 코드리스트 내용을 기준으로 각 변수를 choice / range / date / free_text 중 하나로 자동 분류합니다.
classification_reviewed.xlsx를 업로드했다면 그 값을 그대로 보여줍니다.

|유형|설명|valid_value 입력 예시|
|choice|입력 가능한 값이 정해진 변수|0\|1\|2|
|range|입력 가능한 숫자 범위가 정해진 변수|0~10|
|date|날짜가 입력되는 변수||
|free_text|이니셜, 사유, 비고 등 정해진 허용값 없이 자유롭게 입력하는 변수||

* 화면은 유형별 탭(choice / range / date / free_text)으로 나뉘어 있고, 탭 안 표에서 `codelist_type`과 `valid_value`를 직접 수정할 수 있습니다.
* 분류가 모호한 변수는 free_text로 두는 것을 권장합니다.
* 수정 후 **[분류 확정]**을 눌러야 아래 검증에 반영됩니다.
* 확정한 분류는 **[분류 결과를 classification_reviewed.xlsx로 저장]**으로 다운로드할 수 있습니다.

### 5) 날짜 선후관계 규칙 (선택)
3번에서 date로 분류한 변수끼리 "빠른 날짜 ≤ 늦은 날짜" 규칙을 만들어 확인합니다.
date_rules.xlsx를 업로드했다면 그 규칙이 그대로 표시됩니다.

데모 데이터에서는 다음 규칙을 추가합니다.

|빠른 쪽 (earlier)|늦은 쪽 (later)|관계|
|0_스크리닝 \| CAUSEDDT (사고발생일)|0_스크리닝 \| VISITDT (방문일)|1: ≤ (같은 날 허용)|

* 관계는 1(≤, 같은 날 허용) / 2(<, 같은 날 불허) / 3(=, 같은 날짜여야 함) 중에서 선택합니다.
* **[규칙 추가]**로 여러 규칙을 계속 쌓을 수 있고, 표에서 체크 후 **[선택 규칙 삭제]**로 지울 수 있습니다.
* 규칙 목록은 **[날짜 규칙을 date_rules.xlsx로 저장]**으로 다운로드할 수 있습니다.

### 6) 전체 검증 실행
**[전체 검증 실행]** 버튼을 누르면 위에서 확정한 설정 · 코드리스트 분류 · 날짜 규칙을 기준으로 전체 검증이 한 번에 실행됩니다.
기준 시트를 하나도 선택하지 않았다면 버튼을 눌러도 안내 메시지만 뜨고 실행되지 않으니, 2-1)에서 기준 시트를 먼저 선택하세요.

### 7) 오류 및 추출 결과 확인
실행이 끝나면 아래 내용이 순서대로 표시됩니다.

**검증별 오류 건수**

|변수명 대조|코드북과 rawdata의 변수명이 일치하지 않는 항목|
|코드값 검증|코드북에 정의된 허용값·범위를 벗어난 항목|
|방문 누락|대상자별 예상 방문 중 rawdata에서 확인되지 않은 방문|
|공통값 비교|동일 대상자의 공통 정보가 시트마다 다르게 입력된 항목|
|방문일 순서|방문일이 설정된 방문 순서와 맞지 않는 항목|
|날짜 선후관계|4번에서 설정한 날짜 규칙을 만족하지 않는 항목|

**전체 오류 목록**
검출된 모든 오류를 시트 · 변수 · 대상자 · 방문 · 값 · 메시지 형태의 한 표로 모아서 보여줍니다.

**추출 결과 (free_text_unique / 값 패턴)**
* `free_text_unique`: 자유입력 변수에 입력된 값을 중복 없이 정리한 목록
* `pattern_{시트명}`: 각 시트에서 행 조합의 중복을 제거하고 빈도를 보여주는 표. 첫 두 줄은 항목명 · 코드리스트 설명이며, 값이 5개 이상인 변수는 'O'로 표시됩니다.
